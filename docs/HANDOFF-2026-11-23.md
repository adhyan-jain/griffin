# Griffin handoff, 2026-11-23

## Live in production (Lambda version 66 or later; web on Vercel)
- **Notifications:** an outbox delivers each event once; the phone fetches with a cursor, acks, and a tap opens the right page. Routine runs no longer push (`finish_notifier.go`); failures and approvals still do.
- **Payment apps (Android):** `PaymentGuard.kt` / `core/PaymentPause.kt`. Griffin steps aside for bank apps, reopens them fresh, and turns itself back on. The phone has the `WRITE_SECURE_SETTINGS` and usage-access grants.
- **Opportunities (Epoch 16; audit in `docs/epoch16-audit.md`):**
  - **Sources:** Internshala, Unstop and InternDock (leads), plus 124 verified employer boards (Greenhouse, Lever, Ashby, SmartRecruiters, Workable) read in code (`internal/sources/ats`).
  - **Storage:**
    - Canonical identity, snapshots, evidence and source health (migration 000020).
    - Ranking with quoted evidence (`internal/assess`, migration 000021).
    - Detail pages for aggregator leads (`listing_details.go`).
  - **Removed:** the ₹10k floor, and the hardcoded-opportunity tools. The fake referral campaign is paused and fake tasks are archived.
- **Trackers, all written in code:**
  - Internships (from listings), Hackathons (Devpost, Unstop, Devfolio) and Open Source (GitHub, max 5 per project).
  - Communities (Hacker News; Reddit blocks the cloud) with fact-checked "Reply you can send". Replies use `gemini-flash-lite-latest`; the Gemini client falls back on 503 or 404.
  - Alumni (LinkedIn people search on the laptop, read-only).
- **Chat commands:** approve all, approve/reject/cancel/retry a named item, pause/resume a routine. Plus an Archive tab with "Delete all archived".
- **Routine time limit:** routines run inside the 29s Lambda request (`hosts.go` gives 22s); each stops early and resumes on the next run. Leases are reaped on host claims.

## How to deploy
- **Database migrations:** scratchpad `migrate.sh up`. It goes through the Supabase pooler as admin; never print the URL.
- **Backend:** run `infra/ops/deploy-backend.sh lambda --apply` from a clean `git worktree` of HEAD. It needs `AWS_PROFILE=griffin-bootstrap`, `AWS_REGION=ap-south-1`, `INSTANCE_ID`, `API_URL`, `WEB_URL`, `AWS_ACCOUNT_ID` and `BUCKET`.
- **Check:** confirm the `"Version"` line appears; the network here drops often.
- **Web:** deploys on push to master (Vercel).
- **Production DB:** pgx simple protocol, so never pass typed arrays as query arguments.
